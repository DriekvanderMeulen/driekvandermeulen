# @repo/brand

Brand assets and design tokens for the Kiban/Driek Studio project.

## Overview

This package contains brand assets, design tokens, and visual identity resources shared across applications in the monorepo.

## Planned Contents

- Logo assets (SVG, PNG)
- Color palette definitions
- Typography specifications
- Design tokens (spacing, shadows, etc.)
- Brand guidelines

## Usage

Once assets are added, import them in your application:

```typescript
import { Logo } from '@repo/brand/logo'
import { colors, typography } from '@repo/brand/tokens'
```

## Contributing

When adding brand assets:

1. Use SVG format for logos and icons when possible
2. Provide multiple sizes/variants as needed
3. Document usage guidelines for each asset
4. Keep file sizes optimized
